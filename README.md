# RasNode Consultants — website

Pages: `index.html` (home), `recruitment.html`, `consulting.html`, `about.html`, `contact.html`.
Shared files: `styles.css`, `app.js`.

- Form emails: set `CONFIG.hireEmail` and `CONFIG.cvEmail` at the top of `app.js`
